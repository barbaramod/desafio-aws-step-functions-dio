# 🚀 Desafio do Curso: Explorando Workflows Automatizados com AWS Step Functions

Este projeto faz parte do **Bootcamp Code Girls**, no curso **Explorando Workflows Automatizados com AWS Step Functions**, oferecido em parceria com o Santander e a DIO.

## 📌 Descrição

O desafio tem como objetivo **consolidar workflows automatizados na AWS**, utilizando o serviço **Step Functions** para orquestrar diferentes recursos de forma visual, com pouco código e alta integração.

Durante a prática, foram explorados:

* **Integração com Lambda** para processamento de funções;
* **Armazenamento no S3** para entrada de arquivos;
* **Mensageria com SNS/SQS** para comunicação entre serviços;
* **Persistência de dados com DynamoDB**;
* **Monitoramento e logs** via Step Functions.

## 🛠️ Arquitetura

* **Step Functions** → Orquestra o fluxo de execução
* **AWS Lambda** → Executa código sob demanda
* **Amazon S3** → Armazena arquivos de entrada
* **Amazon SNS/SQS** → Envia e recebe mensagens
* **Amazon DynamoDB** → Guarda metadados e resultados

## 🚀 Aprendizados

* Entender na prática a **orquestração de serviços na nuvem**
* Criar **workflows visuais** para coordenar múltiplos recursos AWS
* Aplicar boas práticas de **automação e serverless**
* Documentar projetos técnicos no **GitHub**
